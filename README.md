# Rescata
Busca y guarda lo que WhatsApp esconde.

Comparte desde WhatsApp un video/foto enviado como documento y Rescata lo copia
a tu galería (carpeta "Rescata") o a la carpeta que elijas. Sin internet, sin anuncios.

## Compilar
1. Sube todo este proyecto a un repositorio de GitHub (rama main).
2. Pestaña Actions -> "Compilar Rescata" (corre sola al subir).
3. Al terminar, descarga Rescata.apk desde Releases (o desde Artifacts).
4. Instálalo en el celular (permite "instalar apps desconocidas").
